🐍 Extract Date from URL

Python Program using Regular Expressions

📌 Objective

To extract Year, Month, and Day from a URL using Python Regular Expressions.

📚 Concepts Used

  • Python re module
  • Regular Expressions
  • Pattern matching

💻 Python Program

    AREA SUM, CODE, READONLY
ENTRY
START
    MOV R1, #10
    MOV R2, #0
LOOP
    ADD R2, R2, R1
    SUBS R1, #0X01
    BNE LOOP
STOP
    B STOP
END
